Portable Windows tools

Labidi Disk Analyzer

Windows · single portable .exe

Answers two questions about a disk: where did the space go, and what changed since? Scan a drive and rank folders by size, biggest and most recent files, then snapshot the disk and diff it later to see exactly what an installer or a week of use changed.

  • One static binary, no installer, no dependencies, no admin required
  • No trace: no registry, no AppData, no network
  • Console and full graphical mode from the same file
diskanalyzer.labidi.eu

Labidi Scanner

Windows · single portable .exe

A network scanner for the engineer standing in a comms room with a laptop and no install rights. Run it with no arguments and in seconds you know every device on the subnet: IP, MAC, vendor, hostname and which ports answer.

  • Device discovery, port scan, DHCP check, connection troubleshooting, Wake-on-LAN
  • Table, CSV, JSON or plain-text output, or double-click for a full window
  • Runs from a USB stick; works without admin rights
scanner.labidi.eu

LabidiForensic

Windows · single portable .exe

Reads back what a Windows machine remembers about its own past: every device ever attached, wireless networks joined, programs run, files opened or deleted, sign-ins. Every run ends by saying plainly what it could not read.

  • Devices, Wi-Fi history, program and file activity, sign-ins, all in one report
  • Honest by design: reads, never manufactures, and reports what it could not see
  • Stick-first and dead-box ready; no installer, no admin, no network code
forensic.labidi.eu
